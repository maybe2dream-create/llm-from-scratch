## 2. 발견된 문제

### A. `the-verdict.txt` 파일이 손상되어 있다 — 가장 중요

파일 끝의 82개 줄이 모두 백슬래시(`\`)로 끝난다. 문단 사이 빈 줄이 복사 과정에서 `\`로 치환된 것으로 보인다.

**근거:**

| 항목 | 이 파일 | 책 기준값 | 차이 |
|---|---|---|---|
| 문자 수 | 20,479 | 20,479 | 0 |
| 토큰 수 | **4,772** | 4,690 | **+82** |
| 어휘 크기 | **1,131** | 1,130 | **+1** |
| `\` 토큰 등장 횟수 | 82 | 0 | +82 |

문자 수가 일치하는 것이 오히려 진단의 핵심이다. 빈 줄의 개행 82개가 백슬래시 82개로 **일대일 치환**되었다면 전체 길이는 변하지 않는다. 토큰 초과분(+82)과 백슬래시 개수(82)가 정확히 일치하는 것이 이 가설을 뒷받침한다.

책의 정규식 `([,.:;?_!"()\']|--|\s)`에는 `\`가 구분자로 없으므로, 백슬래시는 걸러지지 않고 **독립된 어휘 항목 하나**가 되어 어휘집에 영구히 남는다.

> **함의:** 앞으로 이 파일로 나오는 모든 숫자가 책과 어긋난다. 2.5절 BPE, 2.6절 슬라이딩 윈도우에서 책과 출력이 다를 때 "내가 뭘 잘못했지"로 한 시간을 쓰게 된다. 원인이 데이터에 있으면 코드를 아무리 봐도 찾지 못한다. **파일을 다시 받는 것이 다음 세션 첫 작업이어야 한다.**
>
> 이것 자체가 이 프로젝트의 주제와 직결된다. 세션 01 §3에서 "데이터는 모델이 무엇을 아는지를 결정한다"고 정리했다. 지금 눈에 보이지도 않는 문자 82개가 어휘집을 오염시켰다. 데이터 포이즈닝 실험(12월)에서 다룰 현상의 가장 작고 무해한 버전을 이미 만난 것이다.

### B. `verdict.py`의 `KeyError` — 원인은 두 겹이다

## 3. 관찰된 것 — 토큰화의 실제 동작

의도적으로 관찰할 가치가 있는 것들이 이미 데이터에 있다. 세션 01 §6의 네 번째 습관("의도적으로 망가뜨린다")에 해당한다.

**Annabel Lee 어휘 142개 중 이런 토큰들이 있다:**

```
'Lee—', 'darling—my', 'love—', 'me—', 'sea—', 'we—', '—that', 'wingèd'
```

책의 정규식은 `--`(하이픈 두 개)는 구분자로 처리하지만 `—`(em dash, U+2014)는 모른다. 그래서 `love—`가 통째로 하나의 토큰이 된다. `love`와 `love—`는 어휘집에서 **완전히 무관한 두 항목**이다. 모델 입장에서 이 둘 사이에는 아무 관계도 없다.

`wingèd`도 마찬가지다. 사람은 `winged`의 시적 변형으로 읽지만 토크나이저에게는 별개 단어다.

Annabel_Lee.txt에는 `\xa0`(non-breaking space)도 섞여 있다. 이것은 파이썬 `re`의 `\s`가 유니코드 공백으로 처리하므로 결과적으로 문제가 없다. **운이 좋았던 것이지 설계가 안전한 것이 아니다.**

> 이 세 가지가 세션 01 §9에서 예고한 "모델이 단어 안의 글자를 볼 수 없는 이유"의 구체적 사례다. BPE(2.5절)가 이 문제를 어떻게 다르게 푸는지 보는 것이 다음 세션의 핵심이다. `love—`를 BPE로 인코딩해서 몇 개 조각으로 쪼개지는지 직접 확인해 볼 것.

**직접 해 볼 것:**
- `tiktoken`으로 `love—`, `wingèd`를 인코딩해서 조각 수 비교
- 같은 문장의 한국어판과 영어판 토큰 수 비교 (세션 01 §9의 "2~3배" 주장을 실측으로 검증)
- `re.split` 정규식에서 `--`를 빼고 돌려서 어휘가 어떻게 변하는지 관찰

## 부록: 검증에 사용한 코드

```python
import re
t = open("the-verdict.txt", encoding="utf-8").read()
pre = [i.strip() for i in re.split(r'([,.:;?_!"()\']|--|\s)', t) if i.strip()]
print("chars:", len(t))          # 20479  (책과 일치)
print("tokens:", len(pre))       # 4772   (책 4690 — 불일치)
print("vocab:", len(set(pre)))   # 1131   (책 1130 — 불일치)
print("backslash:", pre.count("\\"))  # 82
```

재취득 후 이 스크립트를 다시 돌려 `4772 → 4690`, `1131 → 1130`, `82 → 0`을 확인할 것.
